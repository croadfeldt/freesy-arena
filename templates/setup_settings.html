Audience Score Position and Chroma Key

Raise the Match Introduction and Match Play score overlay by this many pixels. Applies to bottom placement only. Default: 0. Reload the audience display after saving.

Sets the default alliance sides for audience display URLs without a reversed value. An explicit reversed=true or reversed=false in the URL takes priority. Double-click the display to flip sides.

When enabled, replaces the audience display's configured background color. Reload the audience display after saving. Disable to use its configured background again.

Audience Display Automation

Automatically advance the Audience and Wall displays after a score is posted. All durations are in seconds. Changes take effect on the next score posting.

Qualification: Final Score → Match Intro. Playoffs: Final Score → Bracket → Match Intro (Finals/Overtime skip the bracket). After the last match, the display holds for the additional duration before switching to the logo. Manual display changes cancel the remaining automation.

Audience Rankings Display

Choose up to four statistics displayed alongside team rank and number. These choices apply to both Fullscreen and Minimal rankings on the Audience and Wall displays.

Rank and team number are always visible.

Nexus

Automatically populate practice and playoff match lineups from Nexus. Uses the same event code as TBA- configure it on the publishing tab.

When enabled, Nexus is the source of truth for lineups and they can not be overridden by the scorekeeper. To make changes, update the lineup in Nexus or disable this setting.

Nexus AutoQueue: The queuing status in Nexus can be automatically updated when match scores are committed. To generate an AutoQueue key, the TBA event key must be set and you must log in with a Nexus account that has the lead queuer role.

Set the TBA event code on the Publishing tab to use AutoQueue.

Match Video Recording

If you are using a Blackmagic HyperDeck device to record match video, enter the device IP address(es) here to have the arena automatically start and stop recording for each match. Separate multiple addresses with a comma.

BitFocus Companion Integration

If you are using BitFocus Companion for automation, configure the server address/port and button locations (page/row/column) for each event type to automatically trigger button presses during match events. Leave the server address blank to disable the integration.

Note: Enter the IP address and enable the TCP Listener in BitFocus Companion settings. The default TCP port is 51234. Leave address blank to disable Companion integration.

Event Button Mappings

Configure page/row/column coordinates for each event. Set Page to 0 to disable a specific event trigger. Note: Companion uses 0 as a valid row/column number, so only the Page field is used to enable/disable events.
